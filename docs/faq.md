# 常见问题

## Mihomo 是客户端吗？

严格来说，Mihomo 更适合被理解为一个网络代理核心。

各种图形客户端可以调用 Mihomo，让用户更方便地管理配置和控制流量。

## 节点和代理有什么区别？

简单理解：

> 节点是一组具体的代理服务器；代理是更大的概念。

## 为什么配置文件这么复杂？

因为 Mihomo 同时处理：

- 流量进入
- DNS
- 规则
- 代理组
- 节点
- 流量输出

把这些东西拆开理解，就不会觉得配置文件那么神秘。
